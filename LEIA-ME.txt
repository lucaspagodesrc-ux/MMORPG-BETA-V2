ATUALIZAÇÃO 1.32 — NOME DO PERSONAGEM OBRIGATÓRIO E ÚNICO

O QUE MUDOU
- Ao criar um personagem, o nome é obrigatório (2 a 16 caracteres). O campo agora começa vazio.
- Não pode haver nomes repetidos (não diferencia maiúsculas de minúsculas, vale para todas as contas).
  Se o nome já estiver em uso, aparece a mensagem "Esse nome já está em uso. Escolha outro."
- Personagens que já têm nome escolhido por você: continuam exatamente como estão.
- Personagens que ficaram com o nome padrão ("Mago 1", "Assassino 2" etc.): o nome é apagado
  automaticamente quando o servidor sobe. Na lista aparecem como "(sem nome)". Ao clicar neles,
  a tela mostra o campo de nome; só depois de confirmar um nome válido e livre o jogador entra.
  O nome só pode ser escolhido uma vez (nessa primeira entrada).
- NENHUM personagem é apagado. Nível, itens e progresso ficam intactos; só o nome padrão é limpo.
- O servidor também recusa entrar no mundo com personagem sem nome.

COMO INSTALAR
1. Envie TODOS os arquivos deste zip para a raiz do repositório no GitHub (substituindo os existentes):
   index.html, auth.ts, db.ts, rules.js, WorldRoom.ts
2. Aguarde o Render terminar o deploy (a limpeza dos nomes padrão acontece na subida do servidor).
3. No navegador, aperte Ctrl+F5.

OBSERVAÇÕES
- Se já existirem nomes repetidos antigos no banco, o servidor não cria o índice único do banco
  (aparece um aviso no log), mas a checagem de nome repetido continua valendo pelo código do servidor.
- A conta GM não é afetada.
